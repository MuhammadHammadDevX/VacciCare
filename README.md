## 🏛 System Architecture & User Ecosystem

The platform connects three core operational roles with a public discovery frontend:

```mermaid
graph TD
    Public[🌐 Public Portal & Landing Page] -->|Online Registration| ParentAuth[Parent Sign Up / Sign In]
    Public -->|Hospital Onboarding| HospAuth[Hospital Register / Sign In]
    Public -->|Scan QR Seal| CertVerify[Tamper-Proof Certificate Verification]

    subgraph Portals [Core System Portals]
        Admin[👑 Admin Super-Panel]
        Hospital[🏥 Hospital Staff Portal]
        Parent[👨‍👩‍👧 Parent / Guardian Portal]
    end

    ParentAuth --> Parent
    HospAuth --> Hospital
    AdminAuth[Admin Security Gateway] --> Admin

    Parent -->|Book / Request| Appointments[Vaccination Appointments]
    Hospital -->|Administer & Stock Update| Appointments
    Admin -->|Review & Approve| Appointments
    Appointments -->|Issue Official Record| CertVerify
```

## 🗄 Database Blueprint (18 Normalized Relational Tables)

The database schema guarantees relational integrity with explicit foreign key constraints:

| # | Table Name | Purpose & Domain | Key Foreign Keys & Relationships |
|:---:|---|---|---|
| 1 | `users` | Unified authentication accounts with enum role (`admin`, `hospital`, `parent`, `vaccinator`) | Primary user entity for all authenticated stakeholders |
| 2 | `parents` | Extended guardian profiles (CNIC, phone, residential address) | `user_id` &rarr; `users.user_id` |
| 3 | `hospitals` | Medical facilities with license, address, and GPS coordinates | `user_id` &rarr; `users.user_id` |
| 4 | `hospital_users` | Secondary staff and administrative credentials for hospitals | Scoped to hospital institution |
| 5 | `children` | Pediatric profiles (name, DOB, blood group, allergies, notes) | `parent_id` &rarr; `parents.parent_id` |
| 6 | `vaccines` | Master system catalog of approved immunization vaccines | Referenced by hospital stocks and schedules |
| 7 | `hospital_vaccines` | Real-time facility inventory (stock vials, batch numbers, expiry dates, threshold) | `hospital_id` &rarr; `hospitals`, `vaccine_id` &rarr; `vaccines` |
| 8 | `vaccinators` | Healthcare practitioners assigned to administer hospital vaccines | `hospital_id` &rarr; `hospitals.hospital_id` |
| 9 | `parent_requests` | Appointment requests submitted by parents awaiting review | `parent_id`, `child_id`, `hospital_id` |
| 10 | `bookings` | Confirmed appointments with allocated time slots and dates | `child_id`, `hospital_id`, `vaccine_id`, `vaccinator_id` |
| 11 | `vaccinations` | Historical and administered clinical vaccine doses | `child_id`, `hospital_id`, `vaccine_id` |
| 12 | `certificates` | Digital immunization passports with unique verification tokens | `child_id` &rarr; `children.child_id` |
| 13 | `notifications` | Role-targeted notifications and appointment updates | `user_id` &rarr; `users.user_id` |
| 14 | `sessions` | Secure database-backed user sessions | Session storage engine |
| 15 | `cache` & `cache_locks` | Fast key-value application cache storage | Application performance caching |
| 16 | `jobs` & `job_batches` | Asynchronous background queues | Queue workers and scheduled commands |
| 17 | `failed_jobs` | Dead-letter queue tracking failed jobs | Diagnostics and error recovery |
| 18 | `password_reset_tokens` | Secure cryptographic password recovery tokens | Authentication security |

## 🚀 Quickstart & Local Installation Guide

Get VacciCare up and running on your local machine in minutes:

### 1. Prerequisites
- **PHP >= 8.2** with `pdo`, `mbstring`, `openssl`, `gd`, `curl`, and `sqlite3` / `pdo_mysql` extensions enabled.
- **Composer** (PHP Package Manager)
- **Node.js >= 18** and **NPM**
- **MySQL 8.0+** (Running via XAMPP, Laragon, or standalone) OR **SQLite** (included by default)

### 2. Installation Steps

```bash
# 1. Clone repository & navigate to Source Code
cd "Source Code"

# 2. Install PHP Composer dependencies
composer install

# 3. Install Node.js dependencies & compile frontend assets
npm install
npm run build

# 4. Configure environment file
cp .env.example .env
php artisan key:generate

# 5. Run database migrations & seed comprehensive demo data
php artisan migrate --seed

# 6. Launch local development server
php artisan serve
```

The application is now live at:
👉 **`http://127.0.0.1:8000`**

## 🔒 Security, Data Privacy & Compliance

- **Role-Based Access Control (RBAC)**: Custom Laravel middleware guards (`EnsureAdmin`, `EnsureHospital`, `EnsureParent`) protecting endpoints against unauthorized escalation.
- **CSRF Token Validation**: Every state-modifying form is secured against Cross-Site Request Forgery with cryptographic tokens.
- **Password Hashing**: Passwords stored using state-of-the-art `bcrypt` key derivation with 12 rounds.
- **SQL Injection Immunization**: Parameterized queries via Eloquent ORM prevent arbitrary SQL injections.
- **Anti-Counterfeiting Verification**: Certificates are stamped with unique SHA-256 derived alphanumeric tokens verifiable via public QR codes.
- **XSS Sanitization**: Automated HTML entity escaping in Blade view templates.
